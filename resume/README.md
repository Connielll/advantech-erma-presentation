# 個人轉職專用 HTML 互動履歷工作空間 (Career Transition Resume)

這是一個專門為您轉職打造的高質感、響應式全 HTML 個人履歷專案。

---

## 🌟 核心特色

1. **A4 列印優化（Print CSS）**：
   - 點擊右上角「匯出 / 列印 PDF」或在瀏覽器按 `Ctrl + P`，系統會自動切換為高雅白底 A4 版型，隱藏網頁按鈕，直接另存為專業 PDF！
2. **深淺色主題切換（Dark / Light Mode）**：
   - 支援系統偏好偵測與手動切換，適合在螢幕展示、投遞遠端面試作品集。
3. **ATS 友善（Applicant Tracking System Friendly）**：
   - 語意化 HTML5 標籤（`header`, `section`, `h1`, `h2`, `ul`），利於各大人資系統精準解析關鍵字。
4. **專案成果連結**：
   - 內建精選專案卡片，可直接外連展示您剛剛完成的 GitHub 簡報專案與其他技術作品。

---

## 🚀 瀏覽與自訂方式

- **本地預覽**：直接以瀏覽器雙擊開啟 `index.html`。
- **線上展示**：若推送至 GitHub，亦可透過 `https://connielll.github.io/advantech-erma-presentation/resume/` 直接作為線上個人網頁！
